# Provider attribution marks

These small marks identify the service used by the adjacent BUY HARD feature.
They do not imply an endorsement or a partnership. Each name and mark belongs
to its respective owner; no open-source license for these trademarks is claimed.

Retrieved from official public sources on 2026-09-04:

| Asset           | Official source                                                                                             | Usage guidance                                                                                                               |
| --------------- | ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `convex.svg`    | `Logos/SVG/symbol-white.svg` from [Convex's logo archive](https://www.convex.dev/resources/logos.zip)       | [Convex brand guidelines](https://www.convex.dev/brand); the supplied viewBox and clear space are preserved.                 |
| `openai.svg`    | Inline Blossom symbol on [OpenAI's brand page](https://openai.com/brand/)                                   | [OpenAI marks usage terms](https://openai.com/brand/#usage-terms); secondary attribution for actual OpenAI services only.    |
| `firecrawl.svg` | White symbol SVG embedded in [Firecrawl's brand assets page](https://www.firecrawl.dev/brand)               | The brand page explicitly provides the flame symbol for small or square uses.                                                |
| `agentmail.svg` | Small `viewBox="0 0 351 339"` symbol embedded in [AgentMail's official homepage](https://www.agentmail.to/) | Used solely to identify the AgentMail email integration; no separate public trademark license was stated on the source page. |

Original path geometry and viewBoxes are unchanged. Page-only classes and an
unused JSX-style SVG attribute were removed. The UI uses these local files as
monochrome `currentColor` symbols beside the service name, with no runtime
third-party asset requests. Text, controls, and changing data remain live HTML.
